# ai-dev-resources

Resources to help with more effective use of coding agents.

## Skills

The `skills/` folder contains skills that are compatible with both **GitHub Copilot** and **Claude**.

All skills are repo-agnostic, so it's recommended to place them in the user-level settings folder:

- **GitHub Copilot** — Copy the entire `skills/` folder into your `~/.copilot/` directory.
- **Claude** — Copy the entire `skills/` folder into your `~/.claude/` directory.
